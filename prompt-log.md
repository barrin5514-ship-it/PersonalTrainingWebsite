# Prompt Log

Use this file to keep a simple chronological record of AI-assisted changes to the website.

## Prompt 1

### Prompt used

Create a simple, professional, responsive personal website for my coaching and personal training business.

PROJECT REPOSITORY:
https://github.com/barrin5514-ship-it/PersonalTrainingWebsite.git

Use this repository for the project.

## CORE REQUIREMENT

This website must contain EXACTLY THREE main sections:

1. Bio
2. Training
3. Book a Session

Do NOT add any additional main content sections.

Do NOT add testimonials, FAQs, galleries, pricing sections, contact sections, blogs, social feeds, newsletters, or other sections unless I specifically request them later.

The goal for Version 1 is simplicity. Build these three sections well and nothing more.

## SECTION 1 — BIO

Create a professional Bio section introducing me as a coach and personal trainer.

The section should have space for:

- My name
- My photo
- Short biography
- Coaching background
- Martial arts/fighting background
- Training experience
- Coaching philosophy

Use placeholder content where I have not yet provided the actual information.

Make all placeholder content easy to identify and replace later.

Do NOT invent accomplishments, certifications, fight records, statistics, credentials, or other factual information about me.

## SECTION 2 — TRAINING

Create a Training section explaining the types of coaching and personal training I offer.

The design should allow me to list training options such as:

- Personal training
- Boxing
- Muay Thai
- MMA
- Wrestling
- Brazilian Jiu-Jitsu
- Strength and conditioning
- Cardio/fitness training

These are items displayed INSIDE the Training section. They must NOT become separate main website sections.

Each training option can have a short description explaining what clients can expect.

Keep the layout clean, easy to scan, and easy to update later.

## SECTION 3 — BOOK A SESSION

Create a booking section where someone can request a coaching or personal training session.

For Version 1, include a simple booking form with fields for:

- Name
- Email
- Phone number
- Type of training
- Preferred date
- Preferred time
- Optional message or notes

Include ONE primary call-to-action:

"Book a Session"

The booking form only needs to demonstrate the front-end experience for Version 1.

Do NOT create a backend, database, payment system, email system, authentication system, or external scheduling integration yet.

However, organize the code so those features could be connected later without redesigning the entire website.

## DESIGN

The website should feel:

- Athletic
- Professional
- Modern
- Clean
- Strong
- Easy to navigate
- Mobile-friendly

Avoid making it overly complicated or making it look like a generic corporate fitness website.

Use responsive design so it works properly on desktop, tablet, and mobile.

A simple navigation bar may contain:

Bio | Training | Book a Session

These links should scroll to the corresponding sections on the same page.

The navigation bar does NOT count as an additional section.

A simple footer is allowed, but it must remain minimal and must NOT introduce another content section.

## TECHNICAL REQUIREMENTS

Use ONLY:

- HTML
- CSS
- Vanilla JavaScript

Do NOT use:

- React
- Vue
- Angular
- Bootstrap
- Tailwind
- jQuery
- Node frameworks
- Other external frameworks or libraries

Keep the project intentionally simple and beginner-friendly.

Create and use these three website files:

index.html
styles.css
script.js

Use:

- HTML for the structure and content
- CSS for the appearance, layout, and responsive design
- Vanilla JavaScript only where interaction is actually needed

Make sure index.html correctly connects to styles.css and script.js.

The website must be able to run locally by opening index.html in a browser.

Write clean, readable code.

Add useful comments explaining the MAJOR parts of the code so that a beginner learning web development can understand and explain what each file is responsible for.

Do not unnecessarily over-engineer the code.

## PROMPT LOG REQUIREMENT

Create an additional documentation file named:

prompt-log.md

This file is NOT part of the website itself and does NOT count as one of the three website sections.

Use prompt-log.md to document the AI prompts used during development.

Start the prompt log with this original website-building prompt.

For each future prompt, the log should be structured so that we can record:

- Prompt number
- Prompt used
- Purpose of the prompt
- What was changed or created as a result

Keep the prompt log simple, readable, and chronological.

## IMPORTANT SCOPE RULE

The finished WEBSITE must contain EXACTLY THREE main content sections:

1. BIO
2. TRAINING
3. BOOK A SESSION

Nothing more and nothing less.

The navigation bar and minimal footer are allowed as structural elements, but they must NOT introduce additional content sections.

The prompt-log.md file is project documentation and does NOT count as a website section.

Do not expand the project beyond this scope.

This is Version 1.

Prioritize simplicity and code that I can understand and explain over unnecessary features or complexity.

Build Version 1 first. We will review it before making additional changes.

### Purpose of the prompt

Build Version 1 of a simple personal coaching and training website with a tightly defined three-section scope.

### What was changed or created

- Created `index.html`, `styles.css`, and `script.js`.
- Built the Bio, Training, and Book a Session sections.
- Added clearly marked placeholder content for personal details and photography.
- Added responsive navigation, mobile styling, and a front-end-only booking form experience.
